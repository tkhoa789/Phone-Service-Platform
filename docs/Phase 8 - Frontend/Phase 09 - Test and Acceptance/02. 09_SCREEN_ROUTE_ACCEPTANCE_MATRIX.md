## 15.7 Not Found / Fallback Results
- **Unknown Route:** Verified `Route path="*"` exists.
- **Behavior:** `<Navigate to="/dashboard" replace />`.
- **Observation:** There is no dedicated 404 "Page Not Found" screen. Unmatched routes auto-redirect to `/dashboard` (which will recursively push unauthenticated users to `/login`). The fallback behavior does not expose an unauthenticated protected screen based on the inspected routing/guard logic, but might be confusing for users clicking a bad link. (Logged as UX Observation).
