# PC-07 RESPONSIVE REQUIREMENTS

## 1. Hero Banner
- **Desktop:** Flex-row with title on the left and actions on the right.
- **Mobile (<768px):** Flex-col, stacking the title, then the date range picker, then the action buttons. Action buttons should wrap gracefully or stretch to full width.

## 2. KPI Grids
- **Desktop:** 4 columns (`grid-cols-4`).
- **Tablet:** 2 columns (`grid-cols-2`).
- **Mobile:** 1 column (`grid-cols-1`).

## 3. Lists (Branch Performance / System Status)
- Stack vertically on all breakpoints. Ensure text truncates properly on narrow screens.
