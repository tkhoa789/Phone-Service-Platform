# PC-09A Accessibility Requirements

- **Barcode Scanner Support**: The barcode input must gracefully accept rapid keyboard emulation input (typical of USB scanners) without focus stealing from other critical fields.
- **Keyboard Navigation**: Checkout flow must be navigable via Tab / Enter.
- **High Contrast**: Pricing and totals must use high-contrast foreground text (e.g., `text-emerald-600` on light, `text-emerald-400` on dark) for quick scanning.
