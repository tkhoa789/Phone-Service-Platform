# Acceptance Criteria

1. **Architectural Conformity**: 100% of Master Data screens utilize `PageHeader`, `DataTable`, and `AppPagination`.
2. **Design System**: No raw Tailwind gradients, arbitrary hex codes, or legacy neumorphism classes remain in the 5 List pages.
3. **Functional Integrity**: Create, Read, Update, Delete (CRUD) operations work exactly as before.
4. **Pagination Intact**: Server-side pagination remains functional for Customer/Product. Client-side pagination remains functional for Branch/Supplier/User.
5. **No Backend Changes**: No modifications were made to the C# backend API.
