# 07.05 API CLIENT ARCHITECTURE AUDIT

## Current Architecture
- Centralized xiosClient.ts handles generic interceptors (401 rotation, 403, 404, 409, 500 error mapping, correlation IDs).
- Individual [domain]Service.ts files map API endpoints to typed Promise functions.

## Evaluation
- **Strengths**: Centralized interceptor logic ensures robust error handling. Phase 06 idempotency logic was seamlessly integrated into serviceService and salesService.
- **Weaknesses**: Features do not own their API clients. React Query hooks inside eatures/ import from the global services/ directory.
- **Verdict**: The coexistence is intentional during this transitional phase. No urgent migration is required, but eventually, services/ should be absorbed into their respective eatures/*/api/.
