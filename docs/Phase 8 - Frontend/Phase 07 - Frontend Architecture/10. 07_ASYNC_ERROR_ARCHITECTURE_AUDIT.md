# 07.10 ASYNC & ERROR ARCHITECTURE AUDIT

## Current Architecture
- **Global**: xiosClient interceptors catch specific HTTP statuses (401, 403, 409, 500) and dispatch toasts or trigger token rotation.
- **Local (Legacy)**: 	ry/catch blocks inside handleXYZ functions in pages, manually setting loading states and dispatching success/error toasts.
- **Local (Modern)**: React Query's useMutation handles loading/error states, combined with onSuccess/onError callbacks.

## Evaluation
The global architecture is highly robust. Local legacy architecture suffers from boilerplate and potential unhandled promise rejections if 	ry/catch is forgotten.
