# 07.01 FRONTEND ARCHITECTURE BASELINE

## Overview
The frontend is built using React 19, TypeScript, and Vite. It connects to the ASP.NET Core 10 backend via xios.

## Key Discoveries
- **Hybrid Architecture**: The codebase is currently in a transitional state between a legacy pages-centric architecture and a modern eatures-sliced architecture.
- **Legacy Pattern**: src/pages/ + src/services/ + useState/useEffect (e.g., Repairs, Sales, Warranties).
- **Modern Pattern**: src/features/ + src/services/ + React Query + eact-hook-form + Zod (e.g., Branches, Customers, Products, Suppliers).
- **State Management**: Zustand is strictly used for global client state (Auth, Theme, System Settings). Server state is either manually handled in pages or managed by React Query in features.

## Conclusion
The architecture is generally clean but fragmented due to the ongoing transition. No immediate rewrite is required, but standardization should be planned.
