# 07.07 FORM ARCHITECTURE AUDIT

## Current Ecosystem
- **Modern**: eact-hook-form + @hookform/resolvers/zod + Zod schemas (e.g., BranchFormModal.tsx).
- **Legacy**: Controlled inputs via useState + manual validation checks (e.g., WarrantyReplacementModal.tsx, DepositStep.tsx).

## Evaluation
The modern stack is highly robust and typesafe. Legacy forms are prone to bloated component state and inconsistent validation feedback.
