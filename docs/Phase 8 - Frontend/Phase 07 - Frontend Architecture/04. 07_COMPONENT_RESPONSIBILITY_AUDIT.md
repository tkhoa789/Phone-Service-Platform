# 07.04 COMPONENT RESPONSIBILITY AUDIT

## Findings
- **Modern Components (eatures/)**: High separation of concerns. UI components handle rendering, hooks handle data fetching/mutations, schemas handle validation.
- **Legacy Components (pages/)**: Often act as God-components (e.g., RepairListPage.tsx, PosPage.tsx). They contain data fetching, modal state, business logic, form handling, and UI rendering in a single large file.

## Conclusion
Legacy pages violate single-responsibility principles, making them harder to test and maintain.
