# 08.17 UI COMPONENT CATALOG (MINIMUM PRIMITIVE SET)

Based on the audit, the following primitives are required to eliminate the vast majority of Tailwind class duplication (89 button styles, 44 card styles).

## Core Primitives (Required)

### 1. Button
- **Variants**: primary, secondary, success, danger, ghost, outline
- **Sizes**: sm, md, lg
- **States**: loading (spinner swap), disabled, icon-only (requires ria-label)

### 2. Input / Textarea / Select
- Standard borders, focus rings (using design tokens), disabled states.

### 3. FormField
- Encapsulates Label (with required asterisk), Input/Control, and Error message animation.

### 4. Modal / Dialog
- Implements ole="dialog", backdrop blur, consistent z-index, and close button.

### 5. Card
- Standardizes padding, border radius, and the 44 different Neumorphic shadow implementations into one wrapper.

### 6. Badge
- Standardizes status indicators (Pending, Completed, Cancelled) with consistent colors.

### 7. Spinner / Skeleton
- Centralized loading indicators to replace ad-hoc nimate-spin SVGs.

## Optional Primitives (Deferred unless needed)
- Tabs (currently working fine natively)
- Tooltip (nice to have, but low priority)
- Pagination (already exists in components/common/Pagination.tsx and works well)
