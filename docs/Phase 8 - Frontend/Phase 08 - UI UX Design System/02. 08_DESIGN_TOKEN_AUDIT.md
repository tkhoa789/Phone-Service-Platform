# 08.02 DESIGN TOKEN AUDIT

## Centralized Tokens (index.css)
- --neu-bg-base, --neu-text-title, --neu-text-sub, --neu-accent-mint
- --neu-shadow-outer, --neu-shadow-hover, --neu-shadow-inset, --neu-shadow-button

## Finding
Tokens are well-defined for Light/Dark mode but are applied repetitively using extremely long Tailwind class strings instead of being abstracted into a semantic @apply layer or React UI components.
