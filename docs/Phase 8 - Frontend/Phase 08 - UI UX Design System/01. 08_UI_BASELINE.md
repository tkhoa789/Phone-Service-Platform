# 08.01 UI/UX BASELINE

## Overview
The frontend uses a custom Neumorphism design system relying on global CSS variables for colors, shadows, and backgrounds. Components are styled heavily via utility classes (TailwindCSS) instead of abstracted UI components.

## Frozen Constraints
- Architecture migration is deferred.
- API and business logic are fully locked (Phase 06).

## UX General Assessment
- The visual theme is consistent, but implementation is fragmented (over 89 unique button class combinations).
- Accessibility (a11y) is almost non-existent (missing ARIA roles).
- Mobile responsiveness is broken on standard layouts due to hardcoded margins.
